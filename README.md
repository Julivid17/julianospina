# Julián David Ospina — Portafolio

Sitio personal de portafolio y hoja de vida: publicidad, marketing digital, ecommerce y fotografía.
Publicado con GitHub Pages: https://julivid17.github.io/julianospina/

## Estructura

```
index.html          Página (estructura y contenido)
css/style.css       Estilos
js/main.js          Interacciones (menú, animaciones, acordeones, carruseles)
assets/
  img/
    perfil/         Foto de perfil
    casos/          Casos de publicidad (frisby, juda-montes, thajur, banco-de-bogota, colombina)
    fotografia/     Portadas de los álbumes
    desarrollo/     Capturas de los proyectos web
  docs/             Hojas de vida en PDF (ATS y Harvard)
    cartas/         Cartas de presentación e intención
```

## Cómo actualizar

- Cambiar texto o secciones: `index.html`.
- Cambiar colores o diseño: `css/style.css`.
- Reemplazar una imagen: súbela con el mismo nombre a su carpeta en `assets/img/`.
- Los CV se reemplazan en `assets/docs/` conservando el nombre del archivo.
