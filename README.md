# Julián David Ospina — Portafolio

Sitio personal de portafolio y hoja de vida: publicidad, marketing digital, ecommerce y producción audiovisual.
Publicado con GitHub Pages: https://julivid17.github.io/julianospina/

## Estructura

```
index.html                 Página (estructura y contenido)
css/style.css              Estilos
js/main.js                 Interacciones (menú, animaciones, acordeones, descargas con contraseña)
assets/
  img/
    casos/                 Casos de publicidad, una carpeta por marca
      frisby/ · juda-montes/ · thajur/ · banco-de-bogota/ · colombina/
    fotografia/            Portadas de los álbumes
    desarrollo/            Capturas de los proyectos web
  descargas/
    cv/                    Hojas de vida en PDF (ATS y Harvard)
    cartas/                Cartas de presentación e intención
    proyectos/             Proyectos completos cifrados (.zip.enc)
```

## Cómo actualizar

- Cambiar texto o secciones: `index.html`.
- Cambiar colores o diseño: `css/style.css`.
- Reemplazar una imagen: súbela con el mismo nombre a su carpeta en `assets/img/`.
- Reemplazar un CV: `assets/descargas/cv/`, conservando el nombre del archivo.
- Los proyectos se descargan con contraseña: los archivos `.zip.enc` están cifrados y se descifran en el navegador. Para cambiar uno hay que volver a cifrarlo con la misma contraseña (o una nueva).
